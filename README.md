# Hartely-Law-Teams-Page-Renewal

Static drafts for a Hartley Law Group team section.

`index.html` is the homepage. It links to three team-page examples:

- Draft A, editorial profiles (`draft-a-editorial.html`)
- Draft B, portrait grid with practice-area filters (`draft-b-grid-filter.html`)
- Draft C, roster with a sticky profile panel (`draft-c-roster-profile.html`)

“View full profile” and “view profile” open that attorney’s detail page.
